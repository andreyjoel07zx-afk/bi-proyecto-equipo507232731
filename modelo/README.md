# modelo

Modelo predictivo de la pregunta P4 (Entrega 3): víctimas de hurto a personas esperadas por municipio y mes, con seis meses de anticipación.

| Archivo | Contenido |
|---|---|
| `modelo_prediccion_hurto.ipynb` | Notebook de principio a fin: extracción, exploración, preparación, modelado, evaluación, pronóstico y despliegue en `dw.pred_hurto_municipio_mes` |
| `extraccion.sql` | Consulta SQL que arma el conjunto de datos desde el data warehouse |
| `requirements.txt` | Librerías y versiones |
| `figuras/` | Gráficos del notebook y `metricas.csv` |
| `predicciones_hurto_municipio_mes.csv` | Copia de las predicciones de la ejecución de verificación |

Cómo ejecutarlo: ver la sección «Modelo predictivo» del README principal.
